# AGENTS.md

## Architecture

This project is a single static HTML file (`index.html`) with inline CSS. There is no JavaScript, build tooling, framework, or package.json — it is deployed as-is.

## Key files

- `index.html` — the entire site.

## Conventions

- Keep styles inline in the `<head>` unless the project grows enough to warrant a separate stylesheet.
- Avoid introducing a build step or framework unless the scope of the site genuinely requires it.
